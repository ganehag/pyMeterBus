# pyMeterBus 2.0.0a1 release notes

`2.0.0a1` is the first v2 prerelease. It is a breaking rewrite focused on a structured decoder API, deterministic exports, a small CLI, and a dependency-free default install.

This release is useful for previewing the new decoder shape. It is not a complete replacement for every legacy protocol path yet.

## Breaking changes

- v2 is not a drop-in replacement for the legacy object model.
- The package root is intentionally lightweight and v2-focused.
- `import meterbus` no longer guarantees legacy classes, serial helpers, or wireless telegram classes at the package root.
- The default install has no runtime dependencies.
- Optional legacy-adjacent dependencies moved behind extras.
- Supported Python metadata now targets Python 3.11, 3.12, and 3.13.

## Supported public API

Preferred imports:

```python
from meterbus import decode
from meterbus.api import decode
from meterbus.export import to_dict, to_json
from meterbus.model import DecodeMode
```

The package root exports:

```python
from meterbus import decode, decode_one, decode_one_frame
```

`decode()` returns a structured `DecodeResult` with an `ok` flag, decoded frame or telegram data, diagnostics, and the original raw bytes.

## CLI

From a checkout:

```shell
python -m meterbus.cli.decode "E5"
```

After installing the wheel:

```shell
pymeterbus-decode "E5"
pymeterbus-decode --indent 2 "E5"
pymeterbus-decode --mode lenient "10 40 0B 00 16"
```

Exit codes:

- `0`: decode completed and `DecodeResult.ok` is true.
- `1`: decode completed and `DecodeResult.ok` is false.
- `2`: invalid CLI input, such as malformed hex.

## Install and packaging

The default install is intentionally dependency-free:

```shell
python -m pip install pymeterbus==2.0.0a1
```

Supported Python versions for v2 metadata and CI are:

- Python 3.11
- Python 3.12
- Python 3.13

Optional extras are available for non-core workflows:

```shell
python -m pip install "pymeterbus[serial]"
python -m pip install "pymeterbus[yaml]"
python -m pip install "pymeterbus[crypto]"
python -m pip install "pymeterbus[legacy]"
python -m pip install "pymeterbus[all]"
```

The v2 build smoke test verifies that a clean wheel install can run `pymeterbus-decode "E5"` without installing legacy runtime dependencies.

## Implemented decoder coverage

- ACK, short, control, and long frame decoding.
- Strict, lenient, and compat decode modes.
- Checksum and frame diagnostics.
- Variable-data telegram header decoding for CI `0x72`.
- DIF/DIFE parsing.
- Base VIF/VIFE parsing.
- Fixed-length values.
- Clear ASCII and BCD variable-length values.
- Single data record decoding.
- Telegram record loop.
- Record-level VIF scaling.
- Date and datetime interpretation.
- Unknown record preservation in lenient and compat modes.
- `to_dict()` export.
- `to_json()` export.

## Known gaps

- Fixed-data telegram strategy is not finalized.
- Extension VIF table coverage is incomplete.
- More real-world manufacturer fixtures are needed.
- Unsupported or enhanced VIF representation may still change.
- More date/time and variable-length value examples are needed.
- DIF/DIFE storage, tariff, and subunit behavior needs more validation against real telegrams.
- v2 model stability is still preview-level.

## Validation commands

For local validation from a checkout:

```shell
bash scripts/test-v2.sh
bash scripts/smoke-build.sh
```

The focused v2 test suite and build smoke workflow run in CI for Python 3.11, 3.12, and 3.13.
